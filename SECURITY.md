# Security Policy

The Agentic Payments Index is a read-only analytics project. It must never
request a wallet seed phrase, private key, or payment authorization.

Please report vulnerabilities privately to the project maintainer before
opening a public issue. Include reproduction steps, affected endpoint, impact,
and any suggested mitigation. Do not test against third-party upstream systems
beyond normal public API use.

Data-quality disagreements are not security vulnerabilities; use the public
data-correction issue template for those.
